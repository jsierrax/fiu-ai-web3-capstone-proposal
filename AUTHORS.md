## Source Foundation
The original proposal introduced the concept of an AI + Web3 capstone project focused on democratizing access to blockchain through open, intent-based, client-side infrastructure.
Core concepts from the original proposal include:
- Cardano-specialized AI assistant
- Retrieval-Augmented Generation
- Model Context Protocol or MCP-style tool orchestration
- GameChanger Wallet
- Universal DApp Connector
- GCScript DSL
- Client-side workflow execution
- Human-reviewed intent generation
- User sovereignty and inspectable logic
